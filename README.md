# Hi, I'm Naimur Rahman 👋

M.Sc. in Chemistry | Computational Chemistry & Machine Learning

I build models that predict chemical properties from molecular structure. My work covers solubility prediction, toxicity screening, and graph neural networks, with a focus on clean data and honest evaluation.

## Projects

- **[Pesticide Toxicity Prediction (ApisTox)](https://github.com/naimxno/food-contaminant-toxicity)**: honey-bee toxicity of 1,035 pesticides; Random Forest test ROC-AUC 0.76
- **[Multi-task Toxicity (Tox21)](https://github.com/naimxno/Tox21-Toxicity-Prediction-Multi-task-GNN-vs-Random-Forest-)**: 12 assays with a multi-task GNN vs Random Forest
- **[QSAR Solubility Prediction](https://github.com/naimxno/qsar-solubility-prediction)**: aqueous solubility from RDKit descriptors; hold-out R² 0.88
- **[Drug Similarity Finder](https://github.com/naimxno/drug-similarity-finder)**: Tanimoto similarity heatmap for 24 drugs
